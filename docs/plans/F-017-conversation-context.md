# Plan: F-017 whole-conversation context

- **Spec:** [docs/specs/F-017-conversation-context.md](../specs/F-017-conversation-context.md). **No implementation before the user approves the spec (Status: Approved) and answers Q-1 to Q-8.** This plan is a draft that follows the spec as written; if an answer changes the spec, the affected steps change.
- **Scope:** pane code only (`src/taskpane/`), tests, docs. **No change under `supabase/`, no `manifest.xml` change.** The MMSI action is one Entra consent (spec "Draft text for MMSI"), not an upload.
- **Ignore** every file whose name contains `-DIM27` (OneDrive conflict copies); do not edit them.
- **Order constraints:** (1) step 1, the live spike, comes first and decides the shape of steps 3 and 4; (2) the pane can reach `main` before MMSI consents, because `CONVERSATION_CONTEXT_AVAILABLE` is `false` in the committed code; (3) the flag is set to `true` only after steps 11 and 12 (consent and live checks), by the user's decision; (4) no function deploy is involved.
- **Review:** steps 2 to 4 and 6 (new Graph scope, token handling, third-party text) get an **Opus** `code-reviewer` pass.
- **Evidence:** every step records the real command output in "Evidence" when done. `deno test` is not run (Deno is not installed on this machine, as recorded in `status.md`); say so rather than claim it.
